## Lebenslauf

| Jahr | Ereignis |
| --- | --- |
| 1959 | in Rostock geboren |
| 1966-1976 | allgemeine polytechnische Oberschule |
| 1971-1978 | Teilnahme an der Förderklasse für Bildende Kunst am Konservatorium Rostock bei Waldemar Krämer |
| 1976-1978 | Berufsausbildung (Baufacharbeiter) |
| 1978-1979 | NVA |
| 1980-1985 | Studium an der Kunsthochschule Berlin, Weißensee- Sektion Malerei/Grafik, Prof. Dieter Gantz, Heinrich Tessmer |
| 1985 | Diplomarbeit, Mentor Prof. Walter Womacka, Prof. Dieter Gantz |
| seit 1985 | freischaffend Maler und Grafiker |
| seit 1988 | wohnhaft in Stove bei Wismar |
